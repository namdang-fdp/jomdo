# Hộp thư ý tưởng

Đây là nơi thả nhanh link, screenshot, ghi chú hoặc suy nghĩ chưa phân loại về Jomdo.

Khi phân loại:
- Ý tưởng sản phẩm → [[ideas/Idea Log]].
- Bằng chứng công khai có nguồn → research/.
- Quyết định đã thống nhất → decisions/.
- Tầm nhìn hoặc nguyên tắc → product/.
- Khả năng kết nối với Vey → [[integrations/Vey]].

Thông tin nằm trong hộp thư **chưa được xem là quyết định hay dữ kiện đã kiểm chứng**.
